# 构建与发布

## 环境

| 项目 | 本机值 |
| --- | --- |
| Windows | Windows 11 家庭中文版 10.0.26300，x64 |
| CPU | AMD Ryzen 9 7845HX（12 核 / 24 线程） |
| .NET SDK | 10.0.403（LTS，安装在 `D:\Code\.dotnet`，未写入系统 PATH） |
| .NET Runtime | 10.0.14 |
| NAudio | 3.3.0（NuGet，MIT） |
| 目标框架 | `net10.0-windows`，`win-x64` |

本机没有安装 Visual Studio，也没有系统级 .NET；SDK 通过官方 `dotnet-install.ps1` 安装在项目外的 `D:\Code\.dotnet`。所有构建命令都用绝对路径调用 SDK，避免依赖 PATH。

## 还原、构建、测试

```powershell
$env:DOTNET_CLI_HOME='D:\Code\.dotnet-home'
$env:TMP='D:\Code\.tmp'
$env:TEMP='D:\Code\.tmp'
$env:NUGET_HTTP_CACHE_PATH='D:\Code\.nuget-http-cache'

Set-Location D:\Code\ZKeyAudioLink
& 'D:\Code\.dotnet\dotnet.exe' build ZKeyAudioLink.slnx
& 'D:\Code\.dotnet\dotnet.exe' test tests\ZKeyAudioLink.Tests\ZKeyAudioLink.Tests.csproj
```

解决方案文件是 `ZKeyAudioLink.slnx`（.NET 10 默认格式），包含 Core、App、Doctor、Tests 四个项目。

## 自包含发布

```powershell
& 'D:\Code\.dotnet\dotnet.exe' publish src\ZKeyAudioLink.App\ZKeyAudioLink.App.csproj `
    -c Release -r win-x64 --self-contained true `
    -p:PublishSingleFile=false -p:DebugType=None `
    -o publish\ZKeyAudioLink-win-x64
```

说明：

- 不自包含单文件：WPF + NAudio 的依赖较多，单文件容易引入原生库加载问题；交付的是“解压双击”的目录。
- 不启用裁剪：避免音频和 WPF 反射依赖被裁掉。
- 不签名：Windows 可能对未签名程序给出提示；不要指导用户关闭系统防护。
- 包内不包含 VB-CABLE，驱动由用户从官方页面独立下载安装。

发布后建议运行：

```powershell
publish\ZKeyAudioLink-win-x64\ZKeyAudioLink.exe --smoke
```

`--smoke` 不打开窗口，只启动真实音频引擎、注册热键、写日志后退出。正常退出码为 0；在没有 VB-CABLE 的机器上状态应为 `Degraded`，但不应崩溃。

## 开发辅助参数

| 参数 | 用途 |
| --- | --- |
| `--smoke` | 无窗口启动引擎 + 热键并退出，用于设备/自包含启动检查 |
| `--screenshot <png>` | 离屏渲染主窗口到 PNG，用于界面检查，不启动音频、不注册热键 |

两者都不发送键击、不修改系统默认音频设备。

## 图标

`tools/make-icon.ps1` 生成 `src/ZKeyAudioLink.App/Assets/app.ico`（16–256 多尺寸，PNG 压缩的 ICO）。脚本依赖 `System.Drawing`，只在需要改图标时运行。

## 验证工具（Doctor）

```powershell
$doc = 'src\ZKeyAudioLink.Doctor\bin\Debug\net10.0-windows\ZKeyAudioLink.Doctor.dll'
& 'D:\Code\.dotnet\dotnet.exe' $doc list
& 'D:\Code\.dotnet\dotnet.exe' $doc render --in D:\path\test.wav --offset 00:10.000 --out artifacts --mic-tone
& 'D:\Code\.dotnet\dotnet.exe' $doc linktest --seconds 3
```

`render` 用离线混音器把发送流和监听流写成 IEEE-float WAV，不打开播放设备；`linktest` 需要已安装 CABLE，向 CABLE Input 播 1 kHz 音并从 CABLE Output 录回，验证虚拟线两个方向。

## 包里应包含/不应包含

应包含：

- `ZKeyAudioLink.exe`、`ZKeyAudioLink.dll`、Core、NAudio、.NET 运行时。
- `Assets/app.ico`（资源，已嵌入）。
- `使用说明.txt`、第三方许可摘要。

不应包含：

- 开发期间生成的 `Data\`（用户设置/日志）、`artifacts\`、`scratch\`。
- VB-CABLE 安装包或任何驱动文件。
- 用户媒体文件。

## 已知构建注意事项

- 本机的 `%TEMP%` 对某些子进程写入有限制，构建命令使用了 `D:\Code\.tmp`；这不影响最终程序在用户机器的正常运行。
- `dotnet add package` / `restore` 需要网络访问 nuget.org。
- 如果 SDK 升级，需要重新跑测试；不要直接跟踪预览版。
