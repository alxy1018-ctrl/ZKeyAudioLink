# 第三方许可与来源

核实日期：2026-11-01。以下为项目实际使用或用户需要安装的第三方组件；构建时使用的完整 NuGet 包及版本见项目文件。

## NAudio 3.3.0

- 项目：<https://github.com/naudio/NAudio>
- 许可：MIT
- 用途：WASAPI 设备枚举、共享模式播放/采集、WAV/MP3 解码、重采样。
- 本包包含：`NAudio`、`NAudio.Core`、`NAudio.Wasapi`、`NAudio.WinMM`、`NAudio.Midi`。发布包内随附其 DLL。
- NAudio 的 MIT 许可文本随 NuGet 包提供，也可在 <https://github.com/naudio/NAudio/blob/master/LICENSE> 查阅。本项目在 `docs/licenses/NAudio-LICENSE.txt` 保留了完整文本，并随发布包分发。

## .NET 10 / WPF

- 项目：<https://github.com/dotnet/runtime> 与 <https://github.com/dotnet/wpf>
- 许可：MIT
- 用途：运行时、WPF 界面、Windows 桌面基础库。
- 自包含发布包内随附 .NET 运行时文件。完整许可文本保存在 `docs/licenses/dotnet-runtime-LICENSE.txt` 与 `docs/licenses/dotnet-wpf-LICENSE.txt`。

## VB-CABLE（不随软件分发）

- 产品页：<https://vb-audio.com/Cable/>
- 授权页：<https://vb-audio.com/Services/licensing.htm>
- 许可模式：**Donationware**。官方定义：应用可免费使用，全部功能可用（可选功能除外）；厂商希望用户觉得有用时付费，专业用途需要付费授权。
- 本项目的使用方式：建议用户从官方页面自行下载**基础版** VB-CABLE，由用户按官方说明以管理员权限安装并重启。本软件**不捆绑、不静默安装、不修改系统默认设备**。
- 本软件不需要 VB-CABLE A+B / C+D（付费下载类别），也不需要 Voicemeeter。
- 如果后续官方条款变化导致基础版无法免费满足本需求，应停止使用该方案并告知用户，不擅自购买或改成收费依赖。

## Windows 系统组件

- WASAPI、Raw Input、WPF 主题等来自 Windows，随系统提供。
- 本软件不包含第三方图标、字体或音效素材；`Assets/app.ico` 为本项目生成。
