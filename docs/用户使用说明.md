# Z 键音频连麦 · 用户使用说明

## 它做什么

软件把两路声音混合后写进虚拟声卡：

```text
真实麦克风 ─┐
             ├→ 混音 → CABLE Input → CABLE Output → QQ / OOPZ 对方
选中的音频 ─┘
      └────────────→ 你的耳机（只有素材，没有人声）
```

- 对方同时听到**你说话**和**素材**。
- 你自己在耳机里只听到素材，不会听到自己延迟的人声。
- 停止素材不会停止麦克风转发；退出软件才会停止。
- 全局播放快捷键（默认 `Z`，可在播放区改成其他单键）：没播放时从保存的起点播放；播放中再按停止；停止或自然结束后再按从起点重播。
- 按住快捷键只触发一次；`Shift / Ctrl / Alt + 该键` 也算按下；按键不会被吞掉。

## 第一次使用

### 1. 安装虚拟声卡（只做一次）

1. 打开官方页面 <https://vb-audio.com/Cable/>，下载**基础版 VB-CABLE**。不要选 A+B / C+D（那两类需要付费下载）。
2. 完整解压下载的压缩包。
3. 运行与系统架构匹配的安装程序，按官方说明允许管理员权限；安装后**重启电脑**。
4. 重启后，在 Windows 声音设置里应能看到：
   - `CABLE Input (VB-Audio Virtual Cable)`：播放设备，本软件写入它。
   - `CABLE Output (VB-Audio Virtual Cable)`：录音设备，QQ / OOPZ 从它读取。

> VB-CABLE 基础版是 VB-Audio 的捐赠软件：功能可以免费使用，厂商希望觉得有用时捐赠；专业用途需要付费授权。本软件不捆绑、不静默安装驱动。

### 2. 配置本软件

打开 `ZKeyAudioLink.exe`，在“音频设备”里选择：

| 项目 | 选择 |
| --- | --- |
| 真实麦克风 | 你实际使用的麦克风（耳机麦克风 / USB 麦克风 / 内置麦克风） |
| 耳机输出 | 你实际戴的耳机 |
| 虚拟发送端 | `CABLE Input` |

- 如果列表里没有 `CABLE Input`，点“重新连接”；仍未出现就确认驱动装好且已重启。
- “虚拟发送端”只用于写入，不要把它选成耳机输出。
- 第一次运行如果状态显示“部分可用”，把鼠标放在顶部状态文字或看底部说明，会指出缺哪个设备。

### 3. 配置 QQ / OOPZ

在通话软件的语音设置里：

- **麦克风 / 输入设备**：`CABLE Output`
- **扬声器 / 输出设备**：你的耳机
- 不要静音；如果使用“按键说话”，要按住说话键（本软件与通话软件的按键说话互不影响）。

不要做这些事：

- 不要把 Windows 默认播放设备改成 `CABLE Input`。
- 不要在录音设备属性里勾选“侦听此设备”。
- 不需要安装 Voicemeeter。

### 4. 试音

1. 点“导入”，选择一段 WAV 或 MP3。
2. 选中条目；用文本框或滑块设置开始时间（`mm:ss.fff`）。
3. 按播放快捷键（默认 `Z`），同时说话。请对方确认：
   - 能听到素材；
   - 能听到你的说话；
   - 听不到自己的回声。
4. 再按一次快捷键停止，请对方确认你的说话还在。
5. 把“本地监听音量”拉到 0，对方仍应听到素材和人声（本机只是听不到素材）。

QQ 和 OOPZ 要分别测试；软件不能代替真实对端测试。

## 主界面

- **顶部**：音频引擎状态、全局快捷键开关、帮助。
- **左侧音频库**：导入、选中、删除；“从应用库删除”只删除应用管理的副本，不删除原文件。
- **当前音频**：开始时间、播放位置、播放快捷键下拉、播放 / 停止按钮、音频发送音量、本地监听音量。
- **音频设备**：三个设备下拉框、刷新、重新连接、麦克风 / 素材 / 混音电平、麦克风增益。
- **底部**：状态详情、日志入口、驱动下载、版本。
- 中间出现彩色横条时，按右上角 `×` 关闭，或按提示修复设备。

## 全局播放快捷键的行为与限制

- 默认是 `Z`；在当前音频区的“播放快捷键”下拉里可以改成 A–Z、0–9、F1–F12、空格、方向键等主键盘区单键。选择后立即生效并保存。
- 只支持单个按键；不支持组合键、鼠标侧键、媒体键、Win、CapsLock、PrintScreen 等系统键；小键盘区不作为可选键。
- 注意：如果选了 Home / End / PageUp / PageDown 等导航键，小键盘在 NumLock 关闭时可能发送同一个 VKey，因而也可能触发；要严格区分，请选字母、数字或 F 键。
- 软件运行（包括窗口隐藏到托盘/最小化）时，普通桌面上按选定键生效。
- 在记事本、浏览器、输入法、本软件窗口、文件选择框里按选定键也会触发；原窗口仍会收到这个键。
- `Shift / Ctrl / Alt + 选定键` 也算按下；长按只触发一次，必须松开再按。
- 锁屏、UAC 安全桌面、管理员权限窗口、部分带输入保护的游戏可能收不到；不绕过游戏防护。
- 顶部“全局快捷键”开关关闭后，界面按钮仍然可用。

## 隐藏到托盘与退出

- 点窗口右上角关闭：窗口隐藏到托盘，软件和热键继续运行。
- 托盘图标双击 / 左键：显示主窗口。
- 托盘右键 → **退出**：结束软件。
- **退出会停止麦克风转发**，对方将听不到你说话。退出前请：
  1. 先停止素材；
  2. 在 QQ / OOPZ 里把输入切回真实麦克风；
  3. 确认通话正常；
  4. 再从托盘退出。

## 获得好音质的关键

如果对方说“声音发闷、像水下、全损音质”，先按这个顺序处理，不要先怀疑混音：

1. **音频发送音量从 100% 开始，不要用 200% 补音量。** 素材峰值接近 0 dB 时，200% 会让混音限幅器一直工作，听起来会压扁、发破；对方觉得小，优先调 OOPZ / QQ 的麦克风音量或让对方调音量。
2. **用耳机监听，不要外放。** 外放时麦克风会再次拾取素材，形成延迟二重声；通话软件的降噪/回声消除会把它当回声压掉，音质会明显变差。没有耳机时，把本地监听音量拉到 0。
3. **OOPZ：右键左上角调音台 → 关掉“AI 智能降噪”。** 它是为语音设计的，会把持续的音乐当噪声削掉；官方帮助也说明声卡自带降噪与 OOPZ AI 降噪冲突时声音会发糊。戴耳机时再把“回声消除”也关掉；如果开了 AI 美声/音效，一并关掉。
4. **QQ：** 在语音设置里关闭降噪、自动增益、回声消除等处理后再试；不同版本位置不同，以实际界面为准。
5. 如果以上都关了仍然差，换一段 **WAV 或 320 kbps MP3** 复测，并换 QQ 做对照；语音通话本身的码率也会限制音乐质量。

## 故障排查

| 现象 | 检查顺序 |
| --- | --- |
| 本机能听到素材，对方听不到 | 音频发送音量、混音电平、虚拟发送端是否为 CABLE Input、QQ/OOPZ 输入是否为 CABLE Output、通话是否静音或按键说话未按下 |
| 对方能听到素材，但听不到你说话 | 真实麦克风选择、Windows 麦克风隐私权限、麦克风增益、麦克风电平；停止素材不应关闭麦克风 |
| 人声正常，素材断续或被吞 | 通话软件的降噪、自动增益、语音门限；素材音量不要太低；先关掉降噪再试 |
| 声音发闷、像水下、对方说“全损” | 先关 OOPZ“AI 智能降噪 / 回声消除 / AI 美声”；插耳机、不要外放；发送音量回 100%；换 QQ 对照 |
| 声音破、忽大忽小、持续压扁 | 发送音量是否 200%；素材峰值是否接近 0 dB；先把发送音量降到 80–100%，再调通话软件音量 |
| 对方听见自己的回声 | 通话输出必须是耳机；关闭 Windows 侦听；不要捕获系统回放；不要同时开第二套虚拟混音 |
| 自己听到两遍素材 | 关闭 Windows“侦听此设备”，检查是否还有别的监听路由；本软件只保留一路监听 |
| 快捷键一直播放 / 停止 | 检查是否开启了按键重复，或换了触发键；本软件已处理自动重复，若仍出现请附日志反馈 |
| 后台按快捷键无效 | 顶部开关是否打开；是否在锁屏 / UAC / 管理员窗口 / 受保护游戏里；是否选了系统限制键 |
| 卡顿、爆音、延迟累积 | 查看日志中的欠载 / 溢出 / 漂移计数；确认采样率、CPU、设备是否变化 |
| 蓝牙耳机声音变差或断开 | 蓝牙耳机进入双向通话模式会改变端点 / 格式；重新选择设备，优先用有线 / USB 耳机复测 |
| 退出软件后对方听不见 | 这是预期行为；把 QQ/OOPZ 输入切回真实麦克风，或重新启动软件 |

## 数据与隐私

- 配置和媒体库默认在：`%LOCALAPPDATA%\ZKeyAudioLink\`
  - `settings.json`：设备 endpoint ID、音量、热键开关、条目和起点。
  - `Media\`：导入时复制的音频副本。
  - `Logs\`：结构化 JSONL 诊断日志。
- 如果该目录不可写（策略 / 安全软件），程序会依次尝试**程序目录下的 `Data\`**，再退到临时目录；启动日志会记录实际数据目录。
- 配置保存使用临时文件 + 原子替换；损坏的配置会保留为 `settings.json.corrupt-*`，并尝试从 `.bak` 恢复。
- 软件不录制通话、不捕获系统回放、不记录键盘内容；热键日志只记录“选定快捷键按下 / 松开”这类固定事件，不记录其他按键或输入文本。

## 卸载

1. 先停止素材，把 QQ/OOPZ 输入切回真实麦克风，退出软件。
2. 删除解压出来的软件目录。
3. 可选删除 `%LOCALAPPDATA%\ZKeyAudioLink`（会一并删除媒体库副本和日志）。
4. 需要卸载 VB-CABLE 时，按 VB-Audio 官方卸载步骤操作并重启。
