Z 键音频连麦 · 使用说明（快速版）

1. 先安装虚拟声卡（只做一次）
   打开 https://vb-audio.com/Cable/ 下载基础版 VB-CABLE，完整解压，按官方说明以管理员身份安装，然后重启电脑。
   安装后应出现播放设备 CABLE Input 和录音设备 CABLE Output。

2. 打开本软件，选择设备
   真实麦克风：你的麦克风
   耳机输出：你的耳机
   虚拟发送端：CABLE Input
   如果虚拟发送端显示“未检测到”，点“重新连接”；仍失败就检查驱动和重启。

3. 配置 QQ / OOPZ
   麦克风 / 输入设备：CABLE Output
   扬声器 / 输出设备：你的耳机
   不要静音；不要开启 Windows 录音设备的“侦听此设备”。

4. 使用
   导入 WAV 或 MP3 → 选中条目 → 设置开始时间 → 按播放快捷键播放 / 再按停止。
   快捷键默认 Z，可在“播放快捷键”下拉改成其他单键；后台也有效；按住只触发一次；原窗口仍会收到这个键。
   停止素材不会停止麦克风；退出软件才会停止麦克风转发。

5. 退出前
   先停止素材 → 把 QQ/OOPZ 输入切回真实麦克风 → 确认通话 → 从托盘右键退出。

数据位置：
   默认 %LOCALAPPDATA%\ZKeyAudioLink（媒体库副本、配置、日志）。
   如果该目录不可写，程序会在自身目录下创建 Data\，启动日志会记录实际位置。

重要：
   基础版 VB-CABLE 是 VB-Audio 的捐赠软件：个人使用可免费，专业用途需付费授权。
   本软件不捆绑驱动、不静默安装驱动、不改系统默认音频设备，也不录制通话或记录键盘内容。
