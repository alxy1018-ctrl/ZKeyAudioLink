Z 键音频连麦 · 给朋友的使用说明

这是一个 Windows 11 小工具：把真实麦克风和你导入的本地音频混在一起，
送进虚拟声卡，让 QQ / OOPZ 的对方同时听到你说话和素材；你自己耳机里只听到素材。
软件运行后按全局播放快捷键（默认 Q）播放，播放中再按一次从 00:00 重播；按停止快捷键（默认 F8）只停止素材；窗口关闭后会留在托盘。

============================================================
第一次使用：必须先装虚拟声卡（只装一次）
============================================================

1. 打开官方页面：
   https://vb-audio.com/Cable/

2. 下载基础版 New Package：
   VBCABLE_Driver_Pack45.zip
   （1.29 MB，2024-10，支持 XP–Win11 32/64 位和 ARM64）
   不要下 Old package，不要下 Mac 版，也不要下 A+B / C+D（付费类别）。

3. 完整解压 ZIP，右键 VBCABLE_Setup_x64.exe → 以管理员身份运行。
   安装完成后重启电脑。

4. 重启后，Windows 声音设备里应出现：
   - 播放设备：CABLE Input
   - 录音设备：CABLE Output
   如果软件里暂时没看到，点“重新连接”。

============================================================
打开软件并配置
============================================================

1. 解压/保留整个文件夹，双击 ZKeyAudioLink.exe。
   不要只把 exe 单独拷走，旁边的 DLL 和运行时文件必须一起带着。

2. 在软件“音频设备”里选择：
   真实麦克风：你的麦克风
   耳机输出：你的耳机
   虚拟发送端：CABLE Input

3. 在 QQ / OOPZ 的语音设置里：
   麦克风 / 输入设备：CABLE Output
   扬声器 / 输出设备：你的耳机
   不要把自己的系统默认播放设备改成 CABLE Input。

4. 在 OOPZ 里右键左上角调音台：
   - 关闭“AI 智能降噪”
   - 戴耳机时关闭“回声消除”
   - 如果有 AI 美声 / 音效，也关掉
   这一步很关键：OOPZ 的语音降噪会把音乐当噪声处理，声音会发闷、像水下。

5. 软件里导入 WAV 或 MP3，选中条目、设置开始时间，按播放快捷键播放；播放中再按一次从 00:00 重播；按停止快捷键停止。
   默认播放 Q、停止 F8，可在两个下拉里分别改成 A–Z、0–9、F1–F12 等单键；两键不能相同，不支持组合键或鼠标侧键。

============================================================
得到干净音质的几个要点
============================================================

- 音频发送音量先用 100%，不要用 200% 去补音量。
  200% 会让歌曲峰值过载，混音限幅器会一直压着，听起来发破、发扁。
- 用耳机，不要外放。外放时麦克风会二次拾取素材，通话软件的降噪/回声消除会把音乐压坏。
- 对方觉得声音小：先调 OOPZ / QQ 的麦克风音量，或让对方调，不要把本软件的发送音量拉到 200%。
- 本软件本身没有“音效”或“变声”；音质变好通常是因为关掉了 OOPZ 的 AI 降噪/回声消除。
- 如果声音还是不对，换 WAV 或 320 kbps MP3 复测，并换 QQ 对照，排除 OOPZ 语音码率的影响。

============================================================
退出与注意
============================================================

- 关闭窗口只会隐藏到托盘；托盘右键 → 退出 才真正结束。
- 退出会停止麦克风转发。退出前请：
  1) 停止素材；
  2) 把 QQ / OOPZ 输入切回真实麦克风；
  3) 确认通话正常；
  4) 再从托盘退出。
- 不要开 Windows 录音设备属性里的“侦听此设备”，不要捕获系统回放。
- 软件目前支持 WAV 和 MP3，暂不支持 M4A。
- 这是未签名的自包含程序。如果 Windows 提示未知发布者，请确认文件来源可信后
  按系统提示决定，不要为了运行它而关闭系统防护。
- 配置和媒体库默认在 %LOCALAPPDATA%\ZKeyAudioLink；
  如果该目录不可写，会退回到程序目录下的 Data\。
- 本软件不捆绑 VB-CABLE；驱动需要按上面链接自行安装。
  VB-CABLE 基础版是 VB-Audio 的捐赠软件：个人使用可免费，专业用途需付费授权。
- 第三方许可见 docs\第三方许可.md；详细说明见 docs\用户使用说明.md。

祝玩得开心，按快捷键见。
